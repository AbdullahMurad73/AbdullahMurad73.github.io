## التقنيات

صفحة واحدة مكتوبة بـ HTML و CSS خالص — بلا أُطر عمل ولا اعتماديات:

- تصميم متجاوب (Responsive) يعمل على الجوال والحاسب.
- دعم الوضع الليلي والنهاري مع حفظ اختيار الزائر.
- اتجاه RTL كامل مع خط IBM Plex Sans Arabic.
- وسوم Open Graph لمشاركة الرابط على الشبكات الاجتماعية.

## التعديل
